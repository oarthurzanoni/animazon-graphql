# Animazon GraphQL API

A small GraphQL service that supplies catalog data to the Animazon frontend.

## Project goal

Practice designing a GraphQL schema and resolvers in a standalone TypeScript API consumed by a separate client.

## Features

- GraphQL schema for the Animazon catalog
- Queries resolved through Apollo Server
- Typed Node.js source code
- Independent development server

## Technologies

- **TypeScript**
- **Node.js**
- **Apollo Server**
- **GraphQL**
- **UUID**

## What I learned

- Defining a GraphQL schema around client requirements
- Implementing resolvers and data relationships
- Keeping API and frontend concerns separate
- Compiling and running a TypeScript service

## Running locally

```bash
npm install
npm run dev
```

## About this repository

This repository documents a learning project and the technical decisions explored while building it. It is not presented as a production-ready system.
